# hotelroom.agent.botdesk

## The Web2.5 Layer for AI-Agents in Autonomous Hotel & Room Bookings

**BotDesk Hospitality** introduces a cross-chain, open-source hotel and room booking taxonomy for AI agents and PMS integrators, bridging Web2 property systems with automated machine-to-machine (M2M) booking rails. 

For the complete architectural overview, ENS registry details, 7-step taxonomy, and technical roadmap, please refer to the full repository documentation in `README.md`.

**Crucial Architecture Notice:** The core on-chain Payment and Escrow Smart Contract Module is proprietary to guarantee network trust and settlement security. Binding reservations require a certified `settlement_token` via verified partnership.
